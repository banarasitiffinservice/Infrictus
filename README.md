# INFRICTUS Website

A black-and-gold responsive portfolio/service website for INFRICTUS, founded by Saksham Kushwaha.

## Run locally

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

1. Open `script.js` and replace `91XXXXXXXXXX` with the official WhatsApp number (digits only).
2. Replace the placeholder payment details with your confirmed UPI/payment gateway details.
3. Replace sample images/video with final approved media if needed.
4. Confirm that the embedded sample websites permit iframe previews; if not, the Open buttons still work.
